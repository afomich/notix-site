# План раздела Examples — 15 примеров

Дата: 5 августа 2026
Статус: на фильтрацию пользователем

Описания здесь на русском. **Всё, что попадёт на сайт, — на английском.**

---

## Принцип отбора

Две группы по разным основаниям.

**Группа A (8 штук) — под поисковый спрос.** Тема выбирается по объёму запросов,
источник — только со свободной лицензией. Цель: органический трафик от людей,
которые и есть наша аудитория.

**Группа Б (7 штук) — на интерес.** Разные категории, разные типы входа, разная
длина. Цель: показать, что приложение справляется не только с учебниками.

---

## Про «вшить ключи в саммари»

Ключи вшиваются в `<title>`, meta description, H1, лид-абзац и подписи к блокам —
всё это пишем мы. **Саммари, карточки и квиз не редактируются.** Страница обещает
«published as produced»; правка руками превращает обещание в ложь, а весь смысл
раздела — в том, что ему можно верить.

Для ранжирования title весит больше вхождения в теле, так что теряем ноль.

# Группа A — под поисковый спрос

## A1. Интервальное повторение

| | |
|---|---|
| Ключ | `spaced repetition` — **6 600/мес**, конкуренция LOW (1), CPC $2.36 |
| Источник | IES Practice Guide, «Organizing Instruction and Study to Improve Student Learning» (NCER 2007-2004) |
| Ссылка | https://ies.ed.gov/ncee/wwc/Docs/PracticeGuide/20072004.pdf |
| Лицензия | Общественное достояние (Министерство образования США) |
| Объём | 62 страницы |

Государственное методическое руководство: семь рекомендаций, как организовать
обучение, чтобы материал запоминался. Первая — разносить повторение на недели и
месяцы. Написано группой когнитивных психологов, с оценкой силы доказательств по
каждой рекомендации.

**Почему хороший пример:** плотные таблицы, точная терминология, оценки
доказательности — тяжёлый материал, на котором видно, работает ли саммаризация.
И тема совпадает с функцией приложения буквально.

## A2. Активное припоминание

| | |
|---|---|
| Ключ | `active recall` — **9 900/мес** (пик 18 100 в сентябре), LOW (2) |
| Источник | Тот же IES Guide, рекомендации 5 и 6 — про retrieval practice и квизы |
| Лицензия | Общественное достояние |

Второй пример из того же документа, но по другому разделу: почему попытка
вспомнить закрепляет память сильнее, чем перечитывание, и почему квиз — не
проверка, а метод обучения.

**Замечание:** два примера из одного источника — риск, что страницы окажутся
похожи и Google посчитает их дублями. Возможно, стоит взять для A2 отдельный
источник — открытую статью из PubMed Central под CC BY. Решить при фильтрации.

## A3. Метод Корнелла

| | |
|---|---|
| Ключ | `cornell notes` — **60 500/мес** (пик **135 000** в сентябре), LOW (19), CPC $0.12 |
| Источник | Wikipedia, «Cornell Notes» |
| Лицензия | CC BY-SA 4.0 — нужна атрибуция и указание лицензии |

Самый крупный запрос из всех найденных. Метод разлиновки страницы на три зоны:
конспект, ключевые вопросы, итог.

**Слабое место:** Wikipedia стоит в выдаче по этому запросу первой, и пересказом
её не обойти. Ставка целиком на то, чего у Wikipedia нет, — карточки и квиз по
методу. Из всех пятнадцати это самый амбициозный и самый рискованный.

## A5. Метод Фейнмана

| | |
|---|---|
| Ключ | `feynman technique` — **12 100/мес**, LOW (**1**) — минимальная конкуренция |
| Источник | Wikipedia, «Feynman Technique» |
| Лицензия | CC BY-SA 4.0 |

Объяснить тему так, как объяснил бы ребёнку, и в местах, где объяснение
рассыпается, найти пробел в собственном понимании.

**Почему интересен:** индекс конкуренции 1 при двенадцати тысячах запросов —
лучшее соотношение объёма к сложности во всей выборке.

## A6. Как саммаризировать текст

| | |
|---|---|
| Ключ | `how to summarize` — **1 900/мес** + `how to summarize an article` — 1 300/мес, CPC $8.11 |
| Источник | IES Practice Guide, «Improving Adolescent Literacy» (NCEE 2008-4027) |
| Ссылка | https://ies.ed.gov/ncee/wwc/docs/practiceguide/adlit_pg_082608.pdf |
| Лицензия | Общественное достояние |

Руководство по обучению чтению и пониманию текста; раздел про выделение главной
мысли и свёртку.

**Почему это лучший пример из всех:** страница саммаризирует руководство о том,
как саммаризировать. Демонстрация и тема совпадают полностью — приложение делает
на глазах читателя то, о чём документ рассказывает.

## A7. Система Лейтнера

| | |
|---|---|
| Ключ | `leitner system` — **1 000/мес**, LOK (1), CPC $0.64 |
| Источник | Wikipedia, «Leitner system» |
| Лицензия | CC BY-SA 4.0 |

Коробочный метод карточек: угадал — карточка уходит в следующую коробку и
показывается реже, ошибся — возвращается в первую. Прямой предок алгоритмов
интервального повторения в приложениях.

**Почему берём при малом объёме:** конкуренция минимальная, тема — ровно наша
функция карточек, и запрос узкий, то есть люди ищут конкретно это.

| | |
|---|---|

| Источник | на выбор при фильтрации — либо открытая статья из PMC под CC BY про формат карточек, либо раздел IES Guide про квизы |

индексация новых страниц занимает недели. Окно есть, но узкое — группу A имеет
смысл делать первой.

# Что надо решить при фильтрации

1. **A2** — оставить второй пример из того же IES Guide или искать отдельный
   источник, чтобы страницы не читались как дубли
2. **A8** — нужен источник, либо замена темы
3. **Б5, Б6, Б7** — источники названы категорией, не конкретным документом;
   подберу точные после вашей фильтрации, чтобы не тратить время на отсеянное
4. **Категории** — enum в схеме содержит восемь учебных предметов и под этот
   список не подходит; заменяю на: `Learning · Statistics · Science · Health ·
   Culture · Practical`

# Риск, который остаётся

Четыре примера группы A (A3, A4, A5, A7) построены на Wikipedia, а она стоит
выше нас в выдаче по этим же запросам. Мы соревнуемся с источником, на который
сами ссылаемся.

Ставка целиком на то, чего в Wikipedia нет: готовые карточки и квиз по материалу.
Это настоящая добавленная ценность, и именно она отличает добросовестную страницу
от того, что Google считает злоупотреблением масштабированным контентом. Но
сработает ли она как фактор ранжирования — проверяется только публикацией.

Примеры на источниках IES (A1, A2, A6) в этом смысле прочнее: правительственный
PDF в выдаче почти не показывается, и мы не конкурируем с ним напрямую.
