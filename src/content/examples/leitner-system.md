The Leitner system is an efficient spaced‑repetition method for flashcards, introduced by German science journalist Sebastian Leitner in 1972, that organizes cards into boxes so that well‑known items are reviewed less frequently while difficult items are reviewed more often.

## Key Concepts
- **Spaced repetition** – cards are reviewed at increasing intervals based on how well the learner knows them.
- **Learning box** – physical or virtual compartments (boxes) that hold cards of similar mastery levels.
- **Promotion / Demotion** – successful recall moves a card to the next box; failure returns it to the first box.
- **Proficiency‑level system** – a 12‑box variant where each box encodes a session number and cards move according to session‑specific rules.
- **Automation** – modern flashcard software implements the same principles electronically.

## Detailed Notes
### Origin
- Proposed by Sebastian Leitner in 1972 (book *So lernt man Lernen* – “How to learn to learn”).
- Implements the principle of spaced repetition.

### Basic 3‑Box Method
- **Box 1**: cards frequently answered incorrectly – reviewed daily.
- **Box 2**: cards rarely answered incorrectly – reviewed every 3 days.
- **Box 3**: well‑known cards – reviewed every 5 days.
- Correct answer → promote to next box; wrong answer → demote to Box 1.
- Focuses study time on difficult cards, reducing overall study time.

### 12‑Box Proficiency Levels
- Boxes are labeled with four‑digit cycles (e.g., `0‑2‑5‑9`).
- Learning sessions are numbered 0‑9 and repeat cyclically.
- All cards start in **Deck Current** and are reviewed each session.
- Successful cards move to the box whose first digit matches the current session.
- A box is reviewed when its label contains the current session number.
- Unsuccessful cards return to **Deck Current**.
- If a successful card’s last digit matches the session number, it moves to the **Retired Deck**; otherwise it stays.
- Effectively mirrors a 5‑box system but ties boxes to session numbers instead of proficiency levels.

### Automation
- Many computer‑assisted language‑learning tools and flashcard programs incorporate the Leitner principle via “electronic flashcards”.

## Definitions
| Term | Meaning |
|------|---------|
| **Leitner system** | A spaced‑repetition flashcard technique using boxes to schedule reviews. |
| **Promotion** | Moving a card to the next box after a correct recall. |
| **Demotion** | Returning a card to the first box after an incorrect recall. |
| **Deck Current** | The initial box containing all new cards; reviewed every session. |
| **Retired Deck** | Destination for cards that have been successfully recalled at the final stage of a session cycle. |
